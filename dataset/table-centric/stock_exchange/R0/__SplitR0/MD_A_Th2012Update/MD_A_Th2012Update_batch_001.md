# คำอธิบายและการวิเคราะห์ฐานะการเงินและผลการดำเนินงาน

## ภาพรวม

รายได้สูงกว่าค่าใช้จ่ายสำหรับปีสิ้นสุดวันที่ 31 ธันวาคม 2555 เพิ่มขึ้น จำนวน 252 ล้านบาท หรือคิดเป็นร้อยละ 22.70 เมื่อเทียบกับปี 2554 โดยรายได้จากการดำเนินงานเพิ่มขึ้น จำนวน 120 ล้านบาท หรือคิดเป็นร้อยละ 3.70 ที่สำคัญจากธุรกิจตราสารทุน โดยมูลค่าการซื้อขายหลักทรัพย์เฉลี่ยต่อวันและมูลค่าหลักทรัพย์ตามราคาตลาดของตราสารทุนเพิ่มขึ้น และธุรกิจบริการเทคโนโลยีที่เพิ่มขึ้น ขณะที่รายได้ธุรกิจตราสารอนุพันธ์ลดลง ส่วนรายได้จากเงินลงทุนเพิ่มขึ้น จำนวน 230 ล้านบาท หรือคิดเป็นร้อยละ 30.59 ที่สำคัญจากดอกเบี้ยรับเพิ่มขึ้นจากจำนวนเงินลงทุนที่เพิ่มขึ้น สำหรับค่าใช้จ่ายจากการดำเนินงานเพิ่มขึ้น จำนวน 54 ล้านบาท หรือคิดเป็นร้อยละ 2.12 โดยเงินอุดหนุนให้แก่สำนักงาน ก.ล.ต. เพิ่มขึ้นตามมูลค่าการซื้อขายหลักทรัพย์ตราสารทุนที่เพิ่มขึ้น และค่าใช้จ่ายด้านเทคโนโลยีเพิ่มขึ้นจากระบบงานใหม่ที่เริ่มใช้งานในเดือนกันยายน 2555 (ระบบซื้อขายหลักทรัพย์ SET CONNECT ระบบงานเผยแพร่ข้อมูลการซื้อขาย SET FEED และระบบงานกำกับการซื้อขาย SET WATCH) ในขณะที่เงินบริจาคแก่มูลนิธิตลาดหลักทรัพย์ฯ เพิ่มขึ้นจำนวน 95 ล้านบาท หรือคิดเป็นร้อยละ 26.46 โดยจำนวนเงินที่จัดสรร 1/3 ของรายได้สูงกว่าค่าใช้จ่าย เพื่อบริจาคแก่มูลนิธิตลาดหลักทรัพย์ฯ เพิ่มขึ้นตามกำไรที่เพิ่มขึ้น
