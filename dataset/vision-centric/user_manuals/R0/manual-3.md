<!--PAGE 001--># คู่มือระบบ DPIM Portal (SSO)

## ระบบ Authentication SSO

ระบบ DPIM Portal ในส่วนของการ Authentication (Single Sign On: SSO) เป็นระบบหน้าจอสำหรับการ Login SSO เพื่อเข้าใช้งานระบบงานต่างๆ ของ กพร. โดยผู้ใช้งานสามารถ Login เพื่อตรวจสอบสิทธิ์การเข้าใช้งานระบบงานต่าง ตามที่ได้ลงทะเบียนขอใช้งานระบบงานไว้ในขั้นตอนการลงทะเบียนผู้ประกอบการ เมื่อผู้ใช้ทำการ Login ที่ Portal (SSO) เรียบร้อยแล้ว ระบบจะแสดงรายชื่อระบบงานที่ผู้ใช้สามารถใช้งานได้ที่หน้าจอ ผู้ใช้สามารถคลิกที่ระบบงานนั้นเพื่อเข้าใช้งานโดยไม่ต้อง Login ใหม่อีกครั้ง

## การ Login เข้าใช้งานระบบผ่าน SSO

การ Login เพื่อเข้าใช้งานระบบงานต่างๆ ของ กพร. ผ่าน DPIM Portal (Single Sign On) มีขั้นตอนดังนี้

1. เข้าสู่หน้าเว็บ DPIM Portal ป้อนชื่อผู้ใช้ และรหัสผ่าน แล้วคลิก “เข้าสู่ระบบ (Login) ”

ภาพหน้าจอหน้าเข้าสู่ระบบ DPIM Portal (Single Sign On) แสดงช่องกรอกชื่อผู้ใช้ (Username) และรหัสผ่าน (Password) พร้อมปุ่มเข้าสู่ระบบ (Login)

<!--PAGE 002-->2. เมื่อ Login ผ่าน ระบบจะแสดงระบบงานที่สามารถเข้าใช้งานได้ (ตามที่ได้ลงทะเบียนไว้) ดังรูป

ภาพหน้าจอแสดงระบบงานที่สามารถเข้าใช้งานได้ ประกอบด้วย ระบบขอใบอนุญาตส่งออก-นำเข้าแร่, ระบบคำนวณค่าภาคหลวงแร่, ระบบลงทะเบียน (Mining Account) และส่วนการจัดการผู้ใช้งาน

คลิกที่ระบบงานที่ต้องการเข้าใช้งาน จะเข้าสู่ระบบงานโดยไม่ต้อง Login ใหม่อีกครั้ง ดังตัวอย่าง

ภาพหน้าจอแสดงรายละเอียดข้อมูลเอกสารแนบในระบบงานของกรมอุตสาหกรรมพื้นฐานและการเหมืองแร่

<!--PAGE 003-->## การเปลี่ยนรหัสผ่านและกรณีลืมรหัสผ่าน

กรณีผู้ใช้ต้องการลืมรหัสผ่าน หรือต้องการเปลี่ยนรหัสผ่าน จะต้องทำการร้องขอเพื่อเปลี่ยนรหัสผ่าน โดยระบบจะทำการส่งลิงก์พร้อมรหัสความปลอดภัย (Security code) ไปที่อีเมลของผู้ใช้ ตามที่ได้ลงทะเบียนไว้ในระบบลงทะเบียน ผู้ใช้ต้องคลิกลิงก์ในอีเมลเพื่อเปลี่ยนรหัสผ่าน และต้องทำการเปลี่ยนรหัสผ่านภายในระยะเวลาที่กำหนด หากเกินกำหนดต้องทำการร้องขอเปลี่ยนรหัสผ่านใหม่อีกครั้ง ขั้นตอนการเปลี่ยนรหัสผ่านมีขั้นตอนดังต่อไปนี้

1. ที่หน้าจอ Login เข้าใช้งานระบบ DPIM Portal (Single Sign On) คลิกที่ “เปลี่ยนรหัสผ่าน หรือลืมรหัสผ่าน” ดังรูป

ภาพหน้าจอหน้าเข้าสู่ระบบ DPIM Portal (Single Sign On) โดยมีลูกศรชี้ไปที่ลิงก์ "เปลี่ยนรหัสผ่าน หรือลืมรหัสผ่าน"

<!--PAGE 004-->2. ป้อนชื่อผู้ใช้ (Username) แล้วคลิกที่ “ต้องการเปลี่ยนรหัสผ่าน” ระบบจะทำการส่งเมลพร้อม Security code ไปที่อีเมลของท่านที่ลงทะเบียนไว้ โดยแสดงข้อความดังรูป

ภาพหน้าจอหน้าเปลี่ยนรหัสผ่าน แสดงการกรอกชื่อผู้ใช้และมีข้อความแจ้งเตือนว่า "Send mail successfully ระบบได้ทำการส่งอีเมลไปที่อีเมล siripat.si@gmail.com ท่านสามารถเปลี่ยนรหัสผ่านได้โดยการคลิกลิงก์ ที่ระบบส่งไปที่อีเมล"

3. เปิดเมลที่ได้รับจากระบบ แล้วทำการคลิกลิงก์เพื่อเปลี่ยนรหัสผ่าน

ภาพหน้าจออีเมลแจ้งคำร้องขอเปลี่ยนรหัสผ่านจากกรมอุตสาหกรรมพื้นฐานและการเหมืองแร่ แสดงลิงก์สำหรับ Reset รหัสผ่าน

<!--PAGE 005-->4. ป้อนรหัสผ่าน แล้วคลิก “เปลี่ยนรหัสผ่าน” ระบบจะแจ้งผลการเปลี่ยนรหัสผ่านดังรูป

ภาพหน้าจอหน้าเปลี่ยนรหัสผ่าน แสดงช่องกรอกชื่อผู้ใช้, รหัสความปลอดภัย (Security code) , รหัสผ่าน (Password) , ยืนยันรหัสผ่าน (Confirm password) และมีข้อความแจ้งว่า "ทำการเปลี่ยนรหัสผ่านของผู้ใช้งาน usertestcom99 เรียบร้อยแล้ว"
